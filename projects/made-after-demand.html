Interactive website & public installation

Made After Demand

A public-facing digital experience that made an on-demand production process understandable, usable and tangible for visitors.

  • Year2026
  • RoleCreative producer, interaction and visual designer
  • ForPublic event at Nieuwe Instituut

What was done

As an external creative contractor, my role was to translate an on-demand manufacturing concept into a clear customer journey: upload, customise, order and produce. The work included interface states and reusable visual components, developed with a web developer into a functioning website.

For the public presentation, the same logic became an interactive installation. My responsibilities covered technical preparation, visitor flow and institutional delivery.

Delivered

  • User journey and interaction flow;
  • Website interface and reusable components;
  • Developer guidance and testing;
  • Physical installation design;
  • Visitor flow and public presentation;
  • Institutional coordination and reporting;
