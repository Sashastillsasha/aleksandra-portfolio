Dutch Design Week / Fashion Tech Farm

Ornament as Operator

A selected three-screen installation that connects archival embroidery, code and responsive moving images.

  • YearSelected for 2026
  • RoleConcept, research, interaction and visual system
  • ForFashion Tech Farm during Dutch Design Week

What was done

The installation follows how ornament moves between handwork, industrial production and computation. Archival embroidery patterns become coded visual systems that change across three screens.

My role covers the research concept, screen behaviour, visual language and interaction logic, translating a layered design history into a public installation that can be understood without specialist knowledge.

Delivered

  • Research concept and narrative;
  • Three-screen installation structure;
  • Responsive visual system;
  • Interaction logic and screen behaviour;
  • Public-facing communication;
  • Technical collaboration and production preparation;
